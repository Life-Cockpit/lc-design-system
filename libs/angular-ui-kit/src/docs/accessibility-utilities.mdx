# Accessibility utilities

Global classes from `@lifecorner/angular-ui-kit/styles` (`src/styles/_utilities.scss`).
They need no component — put them on your own elements.

## `.sr-only` — visible to screen readers only

Hides content on screen but keeps it in the accessibility tree (it is *not*
`display: none`). Use it for text that sighted users get from the layout or an
icon: a label for an icon-only control, "(opens in a new tab)", the unit of a
number, a heading that structures the page for screen-reader navigation.
`.visually-hidden` is the same rule under another name.

```html
<button type="button">
  <lc-icon name="x-mark" [decorative]="true" />
  <span class="sr-only">Close</span>
</button>

<a href="https://example.org" target="_blank" rel="noopener">
  Example <span class="sr-only">(opens in a new tab)</span>
</a>
```

Do not use it to hide focusable elements — a keyboard user would land on
something invisible. For a link that appears on focus, use `.skip-to-content`.

## `.skip-to-content` — the first link on the page

Lets keyboard and screen-reader users jump past the header to the main content.
Make it the **first focusable element** inside `<body>` and point it at the
`id` of `<main>`. It is moved out of view until it receives focus, then shows
top-left above everything else (above the sticky `lc-header`, z-index 1100).

```html
<body>
  <a class="skip-to-content" href="#main">Skip to content</a>
  <lc-header …></lc-header>
  <main id="main" tabindex="-1">…</main>
</body>
```

- **Contrast:** `--color-on-primary` on `--color-primary-fill` — white on `#1a6a79`,
  **6.21:1** in both palettes (WCAG 1.4.3 asks 4.5:1).
- **Size:** at least **44 px** high (`--size-min-touch-height`).
- **Focus:** an inset 2 px ring in the ink color, visible on the fill.
- **No JavaScript:** a plain fragment link; works in prerendered pages.
- `tabindex="-1"` on `<main>` makes browsers move focus (not only the scroll
  position) to the target.
- Translate the label with the page (`Zum Inhalt springen`).

Try it: click into the box below and press <kbd>Tab</kbd>.
