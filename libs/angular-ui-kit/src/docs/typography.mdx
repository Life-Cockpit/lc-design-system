# Typography

The type system defines consistent font sizes, weights, and line heights.

## Font Families

| Token | Value |
|---|---|
| `fontFamily-base` | -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, ... sans-serif |
| `fontFamily-mono` | 'SF Mono', Monaco, Inconsolata, ... monospace |

## Page titles (3.3)

A scale for a page's own heading that **grows with the viewport**: one token,
the right size on a phone and on a wide screen. Weight 700 (the kit maximum)
for display, title and auth title.

| Token | Phone (360) | 1024 | 1280 | 1440 | 1920 | Use |
|---|---|---|---|---|---|---|
| `--font-size-display` | 40 | 52 | 56 | 60 (`6xl`) | 72 (`7xl`) | the one big greeting (Today); line height 1.05 → 1.02 and letter spacing −0.035 → −0.04 em from 1024 |
| `--font-size-title` | 32 | 40 | 40 | 44 | 48 | every other page title; line height 1.08, letter spacing −0.03 em |
| `--font-size-auth-title` | 30 | 34 | 34 | 34 | 34 | the `<h1>` of sign-in, registration and invitation pages; line height 1.12 |
| `--font-size-overline` | 13 | 14 | 14 | 15 | 16 | the line above a title (a date, a section name); 700, uppercase, letter spacing 0.12 em, `--color-overline` |

Companion tokens: `--line-height-display`, `--line-height-title`,
`--line-height-auth-title`, `--line-height-overline`, `--letter-spacing-display`,
`--letter-spacing-title`, `--letter-spacing-auth-title`, `--letter-spacing-overline`.

### Classes

Put a class on the real heading element. The classes set size, line height,
letter spacing, weight and ink, no margins.

| Class | Sets |
|---|---|
| `.lc-display` | display step, bold, `--color-text-primary` |
| `.lc-title` | title step, bold, `--color-text-primary` |
| `.lc-auth-title` | auth-title step, bold, `--color-text-primary` |
| `.lc-overline` | overline step, bold, uppercase (through CSS: the text stays in sentence case for screen readers and translations), `--color-overline` |

```html
<!-- The date above the greeting, the greeting first in the DOM (one h1 per page) -->
<div style="display: flex; flex-direction: column-reverse; gap: 12px">
  <h1 class="lc-display">Good morning, Johanna</h1>
  <p class="lc-overline">Wednesday, 15 October</p>
</div>
```

## Line Heights

| Token | Value | Usage |
|---|---|---|
| `tight` | 1.25 | Headings, compact text |
| `normal` | 1.5 | Body text (default) |
| `relaxed` | 1.75 | Long-form reading text |

## Usage

```css
font-size: var(--font-size-base);
font-weight: var(--font-weight-semibold);
line-height: var(--line-height-normal);

/* a page title outside lc-page-header */
font-size: var(--font-size-title);
```

```html
<!-- Typography component -->
<lc-typography variant="h1">Heading</lc-typography>
<lc-typography variant="body">Body text</lc-typography>
<lc-typography variant="caption">Caption</lc-typography>
```
