# Internationalization

Every text the kit renders by itself — button labels, accessible names,
placeholders, status words, relative times — is an **input**. Its default is
the text the component has always shown, so nothing changes until you set it.
Dates and times use a **`locale`** input wherever a component formats them.

## Translating labels

Set the inputs per instance. Static values work with Angular's own i18n
(`i18n-<input>` marks a static attribute for translation):

```html
<lc-modal [open]="open" closeAriaLabel="Dialog schließen" i18n-closeAriaLabel>…</lc-modal>

<lc-datepicker
  locale="de-DE"
  [firstDayOfWeek]="1"
  todayLabel="Heute"
  previousMonthAriaLabel="Vorheriger Monat"
  nextMonthAriaLabel="Nächster Monat"
  clearAriaLabel="Datum löschen"
/>
```

Labels that are followed by data are prefixes (`dismissAriaLabel` +
the title, `selectRowAriaLabel` + the row number). Labels with a placeholder
replace it: `{n}` (`minutesAgoLabel="vor {n} Min."`), `{max}`
(`maxTagsReachedLabel`), `{n}` and `{total}` (`digitAriaLabel`).

## Locales

| Component | Input | Default | Formats |
|---|---|---|---|
| `lc-calendar` | `locale`, `firstDayOfWeek`, `labels` | `de-DE`, `1` | month/week/day titles, weekday headers, event times |
| `lc-date-range-picker` | `locale` | `de-DE` | dates, month title, weekday headers (Monday first) |
| `lc-datepicker` | `locale`, `firstDayOfWeek` | `''` (English names), `0` (Sunday) | month title, weekday headers, the day buttons' accessible names |
| `lc-gantt-chart` | `locale` | `de-DE` | month headers |
| `lc-notification-center` | `dateLocale` | `de-DE` | dates older than a week |
| `lc-chat` | `locale` | `de-DE` | message times |
| `lc-log-viewer` | `locale` | `en-US` | line timestamps (24-hour) |

Charts format numbers through `formatValue` and describe themselves through a
generated English summary; set `ariaLabel` to give a chart a translated name.

The defaults are fixed values, not the visitor's browser setting, so server
and browser render the same text — set `locale` to the language of the page.
