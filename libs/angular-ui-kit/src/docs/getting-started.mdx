# Installation

## 1. Install the package

```bash
npm install @lifecorner/angular-ui-kit
```

> **Renamed in 3.3.0.** Up to 3.2.x the package was `@life-cockpit/angular-ui-kit`. Replace that path in imports and `@use` rules; selectors, tokens and the API stay the same.

## 2. Include styles

In your `styles.scss` (or via `angular.json` under `styles`):

```scss
@use '@lifecorner/angular-ui-kit/styles';
```

Or individually — name the partial file with its underscore and extension (the
package's `exports` map points straight at the files):

```scss
@use '@lifecorner/angular-ui-kit/styles/_theme-light.scss';
@use '@lifecorner/angular-ui-kit/styles/_theme-dark.scss';
@use '@lifecorner/angular-ui-kit/styles/_reset.scss';
@use '@lifecorner/angular-ui-kit/styles/_typography.scss';
@use '@lifecorner/angular-ui-kit/styles/_density.scss';
@use '@lifecorner/angular-ui-kit/styles/_utilities.scss';
@import '@angular/cdk/overlay-prebuilt.css'; // overlays: select, datepicker, menu, tooltip …
```

## 3. Use components

All components are **standalone** and can be imported directly:

```typescript
import { Component } from '@angular/core';
import {
  ButtonComponent,
  InputComponent,
  CardComponent,
} from '@lifecorner/angular-ui-kit';

@Component({
  selector: 'app-my-page',
  standalone: true,
  imports: [ButtonComponent, InputComponent, CardComponent],
  template: `
    <lc-card>
      <lc-input label="Name" placeholder="John Doe"></lc-input>
      <lc-button variant="primary" (clicked)="onSubmit()">
        Save
      </lc-button>
    </lc-card>
  `,
})
export class MyPageComponent {
  onSubmit() {
    console.log('Submitted!');
  }
}
```

## 4. Provide HttpClient (for Icons)

The `IconComponent` loads SVGs via HTTP. Make sure `provideHttpClient()` is included in your app config:

```typescript
// app.config.ts
import { provideHttpClient } from '@angular/common/http';

export const appConfig = {
  providers: [provideHttpClient()],
};
```

## 5. Theming

Components use CSS Custom Properties. Choose a theme by setting a CSS class on `:root` or `<body>`:

```html
<!-- Light theme -->
<html class="light">

<!-- Dark theme (also what a root without a theme class gets) -->
<html class="dark">

<!-- Follow the OS setting, no script needed -->
<html class="system">
```

## 6. Component Theming (Header, Sidenav, Logo)

Some components support an explicit `theme` input, allowing them to have a dark or light appearance **independently** of the global page theme.

### Header

```html
<!-- Follows global theme (default) -->
<lc-header [theme]="'auto'" [title]="'My App'"></lc-header>

<!-- Always dark, regardless of page theme -->
<lc-header [theme]="'dark'" [title]="'My App'"></lc-header>

<!-- Always light -->
<lc-header [theme]="'light'" [title]="'My App'"></lc-header>
```

The header sets internal CSS tokens that you can override without touching global neutrals:

| Token | Purpose |
|---|---|
| `--lc-header-bg` | Background color |
| `--lc-header-fg` | Primary text/icon color |
| `--lc-header-fg-secondary` | Secondary text (subtitle, email) |
| `--lc-header-border` | Bottom border color |
| `--lc-header-hover-bg` | Hover background |
| `--lc-header-trigger-border` | Profile button border |
| `--lc-header-trigger-fg` | Profile button icon color |

### Sidenav

```html
<!-- Always dark sidenav with light page -->
<lc-sidenav [theme]="'dark'" [isOpenInput]="true" modeInput="docked"></lc-sidenav>
```

Internal tokens:

| Token | Purpose |
|---|---|
| `--lc-sidenav-bg` | Background color |
| `--lc-sidenav-fg` | Item text color |
| `--lc-sidenav-fg-active` | Active/hover text color |
| `--lc-sidenav-border` | Border color |
| `--lc-sidenav-hover-bg` | Item hover background |
| `--lc-sidenav-section-fg` | Section title color |

### Logo

`lc-logo` shows the LifeCorner logo: Edu, the emblem, and the LifeCorner lockup. It ships its own drawings for light and dark and a small emblem for 32 px and below, so nothing is inverted or recoloured.

```html
<!-- Follows the app theme: light, dark, or the OS under <html class="system"> (default) -->
<lc-logo variant="full" size="md"></lc-logo>

<!-- Always the dark drawing, e.g. on a dark hero -->
<lc-logo [colorMode]="'dark'" variant="full" size="md"></lc-logo>

<!-- Emblem only; xs and sm use the small drawing -->
<lc-logo variant="emblem" size="sm"></lc-logo>
```

Copy the package's `src/assets/` folder to your app's public `/assets/` (or set `LC_LOGO_BASE_PATH`). The logo is flat and fixed: never animate, rotate, recolour or distort it.

## Prerequisites

| Dependency | Version |
|---|---|
| Angular (`core`, `common`, `forms`, `router`, `platform-browser`, `cdk`) | 21 or 22 (`^21.0.0 \|\| ^22.0.0`) |
| TypeScript | the version your Angular major requires (5.9 for 21, 6.0 for 22) |
| Node.js | the version your Angular CLI requires (Angular 22: `^22.22.3 \|\| ^24.15.0 \|\| >=26`) |
| mermaid (optional) | `^11` — only for diagrams in `lc-markdown` |

The package is built with Angular 22 in partial-compilation mode; every release is
checked by building and prerendering a consumer app on Angular 21.0, the latest 21,
22.0 and the latest 22 (`tools/compat/check-angular-majors.mjs`).
